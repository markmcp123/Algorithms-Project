The file that contains our implementation of this proposed algorithm is in 'SortingAlgorithm.java'.

All our necessary methods are in this file so simply clicking 'Run' will run our code fully.

We first print the size of the array that is being used so that the user can simply check at the top ofg the output. Then, we print the negative array, which have been sorted already, all on the same line. 
Then, we simply print the positives in a similar manner. The positive array includes the zero values. 
We then decide to print the original, unsorted array. This is so the user can easily see that the array was originally shuffled and random.

Lastly, we print the time taken. This timer is started before algorithm1 is called and after the original array printed. With small input sizes, the time is, for the most part, virtually zero.
